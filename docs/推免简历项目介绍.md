# 个人刷题系统

## 简历精简版

在线刷题与学习分析系统 | Spring Boot、Vue 3、MySQL、Redis、RabbitMQ

- 独立设计并实现前后端分离的在线刷题系统，支持用户认证、题库管理、Excel 批量导入、随机/专项/错题组卷、自动判分、错题本、考试历史和知识点掌握度分析。
- 后端基于 Spring Boot 与 MyBatis-Plus 构建 REST API，使用 JWT 拦截器实现无状态鉴权，并通过 `user_id` 维度完成多用户数据隔离。
- 设计 MySQL 数据模型，覆盖用户、科目、知识点、题目、考试记录、答题记录、错题本和知识点统计等核心表。
- 使用 Redis 缓存临时试卷题目列表，设置过期时间防止重复提交和题目篡改；使用 RabbitMQ 异步触发知识点掌握度统计更新，降低考试提交链路耗时。
- 前端基于 Vue 3、Vite、Element Plus 实现题库筛选、表单编辑、考试流程、错题维护和统计看板，封装 Axios 统一处理 token、响应结构和异常跳转。

## 简历详细版

在线刷题与学习分析系统

项目简介：面向个人备考场景开发的全栈 Web 系统，支持从题库建设、在线练习、考试记录到错题复盘和知识点掌握度分析的完整学习闭环。系统采用 Vue 3 + Spring Boot 前后端分离架构，后端结合 MySQL、Redis、RabbitMQ 完成数据持久化、临时试卷缓存和异步统计。

个人工作：

- 负责系统整体架构设计与核心模块开发，完成用户认证、题库管理、科目知识点管理、Excel 导入、组卷考试、错题本和数据分析模块。
- 设计并实现 JWT 鉴权流程，登录后签发 token，后端拦截器统一解析用户身份，业务接口基于当前用户上下文访问数据。
- 设计核心数据表及关联关系，包括 `user_account`、`subject`、`knowledge_point`、`question`、`exam_record`、`answer_record`、`error_book`、`knowledge_point_stat`。
- 实现多模式组卷逻辑，支持随机抽题、知识点专项练习和错题练习；提交答卷后自动判分并沉淀错题。
- 使用 Redis 缓存试卷 ID 与题目 ID 列表，并设置 30 分钟有效期，保证考试提交时的题目集合可信。
- 使用 RabbitMQ 将考试提交和统计计算解耦，异步重建知识点作答总数、正确数和掌握度。
- 使用 Apache POI 实现 Excel 题目导入，按表头解析题型、题干、选项、答案、难度、解析、科目和知识点，并返回导入错误明细。
- 使用 Vue 3、Vue Router、Element Plus 和 Axios 实现前端页面与接口联调，完成登录守卫、统一错误处理、题库检索、答题页面和统计看板。

可突出亮点：

- 完成从数据库设计、后端服务、前端页面到联调文档的完整工程实践。
- 在系统中引入 Redis 和 RabbitMQ，体现缓存、异步化和服务解耦设计能力。
- 围绕学习场景建立错题复盘和知识点掌握度反馈闭环，具备清晰的业务建模能力。

## 面试表述版

我做过一个在线刷题与学习分析系统，目标是解决个人备考中题目管理分散、错题复盘不系统、知识点掌握情况不清晰的问题。系统前端使用 Vue 3 和 Element Plus，后端使用 Spring Boot 和 MyBatis-Plus，数据存储使用 MySQL，同时引入 Redis 缓存临时试卷，使用 RabbitMQ 异步更新知识点统计。

在实现上，我先设计了用户、科目、知识点、题目、考试记录、答题记录、错题本和知识点统计等数据表。用户登录后通过 JWT 进行鉴权，后端接口不信任前端传入的用户 ID，而是统一从 token 中解析当前用户，保证用户数据隔离。考试模块支持随机、知识点和错题三种组卷方式，生成试卷时只把题目列表缓存到 Redis，提交时再按缓存题目判分，避免前端篡改题目范围。提交完成后，系统保存答题记录并自动更新错题本，再通过 RabbitMQ 触发知识点掌握度统计，避免统计计算阻塞主流程。

这个项目让我完整实践了前后端分离开发、REST API 设计、数据库建模、JWT 鉴权、缓存和消息队列的使用，也锻炼了我把具体学习场景抽象成系统模块的能力。
